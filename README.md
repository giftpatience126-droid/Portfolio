# Patience Gift — Personal Portfolio

A responsive, single-page portfolio for Patience Gift, an Applied Computing student at KCA University. The site presents her education, technical skills, three web projects and contact links.

## Project files

- `index.html` — semantic page structure and portfolio content
- `style.css` — responsive layout, slate and cyan theme, hover effects and reduced-motion support
- `images/patience-gift.jpeg` — profile portrait

## Preview locally

Open `index.html` in a browser. The site uses no build tools or JavaScript. Google Fonts are an optional enhancement; system font fallbacks are included.

## GitHub Pages publishing

1. Create a public GitHub repository named `personal-portfolio` and add the description: “A responsive personal portfolio for Patience Gift, built with semantic HTML and CSS.”
2. Add this project as the repository contents and push the `main` branch.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for the deployment to finish and verify the published page and profile photo.

## Assignment checklist

- Semantic `header`, `nav`, `main`, `section` and `footer` elements
- Home, About, Skills, Projects and Contact sections
- Headings, paragraphs, hyperlinks, ordered and unordered lists, a profile image, data table, contact form and input fields
- External stylesheet, CSS classes and ID selectors, spacing, borders, hover effects, CSS Grid/Flexbox and mobile breakpoints
- Three project entries with links: Kenya House Listings, GiftNest and Faith Connect
- Bright, airy canvas with sky blue, cyan, emerald, lime, coral and lavender accents

## Before submission

- Check the email, GitHub, Instagram and phone links.
- Open each navigation link and confirm the portrait displays.
- Review the page at desktop and mobile widths; capture both screenshots for the assignment.
- Validate the HTML and CSS and verify the GitHub Pages URL after publishing.
