# Your Name — Personal Portfolio

A responsive, single-page portfolio website built with semantic HTML and external CSS. The visual direction is editorial and calm: warm paper tones, deep forest green, generous spacing, and small handmade-style project illustrations.

## Project files

- `index.html` — page content and semantic sections
- `style.css` — layout, responsive styles, hover states and reduced-motion support
- `images/profile-illustration.svg` — locally stored illustrated portrait placeholder

## Make it yours

Before submitting or publishing, search `index.html` for the square-bracket placeholders and `your.email@example.com`, then replace them with your details. In particular, update your name, course, institution, interests and email address. Replace the SVG portrait with a suitable profile photo if you have one (keep the image path or update the `<img>` source). The three portfolio entries are clearly marked as proposals; replace them with completed work when available. Review the skills and location so they describe you accurately.

## Preview locally

Open `index.html` in a browser. The site uses no build tools or JavaScript. Google Fonts are an optional enhancement; system font fallbacks are included.

## Publish with GitHub Pages

1. Create a public GitHub repository named `personal-portfolio` and add a meaningful description, for example: “A responsive personal portfolio website built with semantic HTML and CSS.”
2. In this project folder, initialize Git if needed, commit the source files and set the repository as the `origin` remote. Push the `main` branch to GitHub.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for the Pages deployment to finish. The published URL appears in the Pages settings. Check that the page and portrait load from that URL.

## Suggested meaningful commit sequence

1. `chore: create portfolio project structure`
2. `feat: add semantic portfolio sections and navigation`
3. `feat: style responsive portfolio layout`
4. `feat: add project cards, profile illustration and contact form`
5. `docs: add project setup and GitHub Pages instructions`

## Assignment checklist

- Semantic header, nav, main, section and footer elements
- Home, About, Skills, Projects and Contact sections
- Headings, paragraphs, hyperlinks, ordered/unordered lists (project technology lists), a data table, image and contact form
- External stylesheet, CSS classes and ID selectors, spacing, borders, hover states, CSS Grid/Flexbox and mobile breakpoints
- Local SVG image so the portrait artwork does not depend on a remote image host
- Sample project proposals are labelled honestly; personal details are editable placeholders
