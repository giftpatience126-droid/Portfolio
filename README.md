# Patience Gift — Personal Portfolio

## Project overview

This repository contains the personal portfolio website of Patience Gift, an Applied Computing student at KCA University. The website introduces Patience, highlights her education and technical interests, presents selected web projects, and provides ways to get in touch.

The design uses a bright, airy visual style with pale blue and mint surfaces, white cards, and cyan, emerald, lime, coral and lavender accents. Dark blue-gray text keeps the content easy to read. Responsive layouts adapt the page to desktop and mobile screens.

## Website sections

- **Home:** A short introduction and profile photo.
- **About:** Patience’s Applied Computing studies, Modcom short course, and interests in reading, singing, novel writing and ziplining.
- **Skills:** Java, Python, HTML, CSS, C#, React, and introductory machine learning and data science.
- **Projects:** Three web projects covering property and hospitality search, online gifting, and faith and youth community.
- **Contact:** Email, telephone, GitHub, Instagram and a contact form that opens the visitor’s email application.
- **Profile snapshot:** A compact table with location, education, training and interests.

## Featured projects

### Kenya House Listings

A property and hospitality search website for finding apartments, booking Airbnb stays and discovering restaurants. [Visit the live website](https://kenyahouselistings-alpha.vercel.app/).

### GiftNest

A web project exploring an online experience for finding and sharing thoughtful gifts. [View the GitHub repository](https://github.com/giftpatience126-droid/giftnest).

### Faith Connect

A website designed to help young people strengthen their faith and find encouragement in community. [Visit the live website](https://faith-connect-l23k.vercel.app/).

## Technologies and techniques

- Semantic HTML for page structure and accessible content.
- External CSS for typography, color, responsive layouts and visual states.
- CSS Grid and Flexbox for page and card layouts.
- Responsive breakpoints and reduced-motion preferences.
- HTML forms, links, lists, images and a data table.
- A locally stored JPEG portrait image.

## Repository structure

- `index.html` — portfolio page content and semantic structure.
- `style.css` — complete visual theme and responsive styling.
- `images/patience-gift.jpeg` — profile portrait used on the home section.
